# Molly

Product and implementation backlog for **Molly**, a native macOS menu bar + dashboard app focused on lid-closed “keep agents running while the display sleeps,” with an optional jittered hotspot keepalive lane.

Frozen **v1** scope (SKU split, probes, UX skeleton, MVP acceptance shorthand) lives in [`spec/molly-v1-frozen-spec.md`](spec/molly-v1-frozen-spec.md). Xcode targets and Swift sources are intentionally not in this workspace yet—they must be created on macOS hardware.
